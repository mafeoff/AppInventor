## How to reopen a project

1. Go to [ai2.appinventor.mit.edu](https://ai2.appinventor.mit.edu) and log in.
2. Under **Projects → Import project (.aia) from my computer**, select the `.aia` file from the desired folder.
3. The project will open with the Designer and Blocks views intact.
