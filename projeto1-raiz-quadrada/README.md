# COTEMIG_AULA_3_1B2 — Square Root Calculator (MIT App Inventor)

Small single-screen classroom exercise (Class 3) for the Computer Science/IT class.

**Original date (internal metadata of the `.aia` file):** 09/03/2021

## What the app does
A basic calculator: the user types a number into `txt_Raiz`, taps `btn_Calcular`, and the app computes its **square root** (a `math_single` block with the `ROOT` operator) and shows the result in `lbl_Resultado`. If the field is left empty, `lbl_Aviso` shows a message ("Digite um número"). `btn_Limpar` resets the fields.

## Components used
- `TextBox` for the number input
- 2 `Button` (Calculate / Clear)
- `Label` components for result and warning message
